# 🥖 Panifica Gestor Pro

Sistema completo de gestão financeira e operacional para padarias.

## 🚀 Sobre o Projeto

O Panifica Gestor Pro foi desenvolvido para auxiliar padarias no controle de:

* Contas a pagar
* Fornecedores
* Estoque
* Produção
* Fluxo de caixa
* Relatórios financeiros
* Dashboard gerencial

Tudo em uma plataforma moderna, rápida e intuitiva.

---

## 📌 Funcionalidades

### Financeiro

* Cadastro de contas a pagar
* Controle de vencimentos
* Histórico de pagamentos
* Alertas financeiros

### Fornecedores

* Cadastro completo
* Histórico de compras
* Controle de contatos

### Estoque

* Entrada e saída de produtos
* Controle de estoque mínimo
* Alertas de reposição

### Produção

* Registro de produção diária
* Controle de insumos
* Acompanhamento operacional

### Dashboard

* Indicadores em tempo real
* Resumo financeiro
* Gráficos gerenciais
